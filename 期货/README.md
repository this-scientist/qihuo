## 前端总览与因子配置

在 `D:\project\期货` 启动：

```powershell
.\.venv\Scripts\python.exe '期货\dashboard_server.py' --asof 20260911
```

浏览器打开 <http://127.0.0.1:8765/>。省略 `--asof` 时使用最近一次准备好的历史日期，`--port` 可更换端口。服务只监听本机；启动时重新校验并计算已有数据，不访问行情接口，不向前端发送访问令牌。

- 首屏展示黑色、贵金属、有色与新能源、能源、化工、农产品和其他大类的等权对比曲线。点击大类展开全部有效品种，点击图例显示或隐藏曲线。支持20/60/120/250交易日。
- 右侧任意添加因子，勾选启用，设置大于、小于、等于、区间或与另一个因子比较；信号因子支持成立/不成立。百分比直接输入百分数，比如涨幅5%输入5。
- 组合支持AND/OR、多头/空头口径。点击“应用筛选”更新结果；没有条件时浏览全部。“显示未通过”可以查看失败/缺失的逐条件明细。
- 点击结果品种查看真实主次合约、复权走势与MA20/60/120；“对比筛选品种”将匹配结果叠加到主图。
- 配置保存在当前浏览器，可导入/导出JSON；匹配结果可导出CSV。自定义条件不额外套用旧榜单门槛，原版趋势/启动分及模块分保留原有定义。
- 分类及品种名称在 `sectors.json`。类内有效品种在窗口共同起点归一化后等权平均，非交易所指数；无成交、历史不足或价格无效品种不进入图表。基差/现货因子可以选择，但因数据未接入不会通过比较。

新交易日先运行下面的 `screen_futures.py --refresh-history`，再重启总览服务。页面展示的是所选收盘日快照，观察窗口只改变图表范围，不改变筛选指标日期。

页面无Node构建与图表CDN依赖。浏览器验收脚本为 `tests/check_dashboard_browser.py`（仅开发验证需要额外安装Playwright，并使用本机Edge）。

## 趋势筛选（已实现）

筛选器按最初策略计算0—100趋势分与启动分，分别输出多空已确认趋势榜和启动观察榜。默认ADX>=20、启动方向RPS20>=90、启动分>=65、趋势分>=70、至少6项启动信号、偏离不超过3ATR。无合格品种时不凑名单。

```powershell
# 第一次：获取指定收盘日的主次合约，补齐历史，复权并筛选
.\.venv\Scripts\python.exe '期货\screen_futures.py' --asof 20260911 --refresh-history

# 后续同一日：只重算筛选，不联网
.\.venv\Scripts\python.exe '期货\screen_futures.py' --asof 20260911

# 新收盘日：更新当日与所需历史数据后筛选
.\.venv\Scripts\python.exe '期货\screen_futures.py' --asof 20260914 --refresh-history

# 单独准备历史，暂不筛选
.\.venv\Scripts\python.exe '期货\prepare_history.py' --asof 20260911
```

交易日必须明确提供；周末/休市不会生成正式榜单。`--data-dir` 可使用隔离目录，`--settings` 可指定评分配置文件。默认配置为 `strategy_config.json`，参数含义与逐项分值见 [评分规则](docs/评分规则.md)，设计见 [趋势筛选设计](docs/趋势筛选设计.md)。

筛选器的技术价格使用自行校验的主力换月复权历史，区别于下面基础采集器输出的未复权走势。历史仅获取过去曾经成为主力的合约和当前次主力，换月重叠报价用于消除价差。首次下载较慢，按品种输出进度；成功的接口结果有哈希缓存，失败后重跑会复用已完成请求。滚动历史窗口的日期变化会生成新的范围缓存，当前未实现跨范围增量复用。

至少280根连续有效主力K线；新品种或主力价格缺失会排除，篮子少于20个时正式榜单为空且退出码1。基差未接入；固定主力/次主力量仓不可比较时模块标记缺失，默认覆盖率低于90%不入榜。当前两合约量仓不是全品种OI。

筛选输出在 `data/processed/radar/<asof>/`：

- `daily_report.md`：可直接阅读的多空启动观察与已确认趋势日报。
- `long_startup.csv`、`short_startup.csv`：启动观察前5，可能不足5或为空。
- `long_trend.csv`、`short_trend.csv`：已确认趋势前5。
- `scores.csv`：全部品种两方向分项、总分、命中信号和门槛状态。
- `indicators.csv`：收盘、MA/RPS/ADX/ATR、发散度、固定量仓、月间价差等原始指标。
- `exclusions.csv`、`quality.json`：排除原因、篮子覆盖、参数及结果数量。

复权历史位于 `processed/history/`，换月审计文件同名后缀 `.rolls.csv`；当前固定月对近期行情位于 `processed/pair_history/`。这套筛选只产生品种观察名单，没有检查期权IV、期限或盘口。

默认只采集 DCE、CZCE、SHFE、INE、GFEX，不含中金所。

## 当前范围

- 主连走势：根据 `fut_mapping` 标准主力代码（如 `M.DCE`）对应的真实月份合约生成日线。
- 主力：遵循当天官方接口主力映射，不用成交量排名替换。
- 次主力：主力之外，有成交的标准月份合约中持仓量最大者；持仓相同按成交量降序、代码升序排序。
- 无成交品种、映射主力无成交的品种跳过并记录原因；没有有成交次主力时只保留主力。
- 每个交易所每天读取一次日行情快照以识别次主力，仅保存选中的两个合约，不保存全合约快照、不下载全月份合约历史。不再依赖全量 `fut_basic` 的合约覆盖，因此非入选远月合约元数据缺失不会阻挡采集。
- 不自动下载仓单、持仓排名、结算参数、期权或现货数据。原全合约采集层 `collector.py` 留作参考，当前命令行不调用其 `run`。

主连是 **未复权** 的主力拼接序列，`adjustment=none`、`series_source=mapped_real_main`。它保留真实主力价格，换月可能出现价差跳空。`mapping_ts_code` 标识每天使用的真实合约；`roll_changed` 与最近已有日期比较，第一条或无上一条时为空。跨缺失交易日比较的标记不能定位中间每次换月。不得直接将换月跳空当成突破、RPS涨跌或ATR扩张；趋势指标计算前需要另行校正。当前数据服务的 `fut_daily_adj` 测试返回 `2003`，所以当前范围不依赖该接口。

OI 只代表主力、次主力各自持仓，两个相加也不代表全品种总持仓；后续资金评分应按此口径调整。两个合约的角色不是近远月，计算月间价差时需按实际交割月份确定顺序。


读取合并结果前核对 `success`、`exchanges` 和 `published_days`。退出码0表示所请求任务完成，1表示有失败任务。重跑复用哈希与参数匹配的选中合约/主连分区，文件损坏或无校验凭据时重采；当日或供应商修订数据用 `--force` 刷新。失败分区不发布当天合并结果，已有顶层文件可能是旧结果，不代表本次成功。

选中的真实合约校验交易日期、交易所、数值、OHLC和重复记录。非入选零成交合约不阻挡采集；有成交但缺主力映射、入选合约价格无效、响应达到上限时报告失败，避免错误选择次主力。当前仅支持单实例写同一目录。

配置保留 `config.py` 的本地服务地址及凭据，也支持 `TUSHARE_TOKEN`、`TUSHARE_HTTP_URL`、`TUSHARE_REQUEST_INTERVAL`（默认0.8秒）、`TUSHARE_REQUEST_TIMEOUT`（默认30秒）环境变量。凭据不应公开上传。模块导入不会联网。

## 期权扫描

`/scanner.html` 每天把全部商品压缩成多头、空头各前5个候选，再为每个候选自动挑出主仓与彩票仓合约，对应“买方抓大级别趋势启动”的工作流：先筛选品种，再挑合约。

- **爆发指数**：十项加权求和——RPS强度15、RPS加速度10、ADX加速度10、突破强度10、OI变化10、成交量5、库存/基差10、期限结构10、IV相对HV溢价10、期权流动性10。数据缺失的模块按可用权重归一（比如库存未导入时满分90），分数不是简单的绝对和。
- **十条组合信号**：RPS进入方向前10%、RPS五日上升≥10、ADX拐头且DI同向、突破20/55日平台、OI五日增加、温和放量、现货/基差同向、期限结构同向、IV未过热（≤HV1.3倍且≤60）、期权量仓≥1000。满足8条以上才值得重仓研究；数据缺失的信号不计入分母。
- **合约挑选**：主仓|Delta|0.20–0.55、彩票仓|Delta|0.08–0.20，期限优先20–60自然日；候选池没有20–60天合约时依次放宽到10–60天、7–120天（档位标注说明，远月Gamma较低），不足7天的近月直接排除。同一档位内按贴近目标Delta（主仓0.35、彩票仓0.14）与流动性挑选。没有任何可评估期权的品种（无链或全部合约落在期限窗口外）在榜单中沉到有合约品种之后。点击候选行查看十项分解、逐条信号与合约表，并可跳转期权观察页核对。
- **期限结构（真实月合约数据线）**：与趋势指标的复权主连严格分离。Carry 动量来自固定主次对（未复权结算价）的年化序列：`Carry=(近/远−1)×365/月间隔`，Carry>0 为 Backwardation、<0 为 Contango、±0.1% 内为平坦；Carry 五日/二十日变化与五日内符号翻转即"期限结构拐点"。爆发指数期限项按梯度打分：方向对齐6分＋年化Carry≥2%加2分＋Carry动量同向加2分（缺 Carry 时回退旧月间价差二值口径）。
- **四重共振**：RPS拐点（五日上升≥10）＋ADX拐头＋OI五日增加＋期限结构拐点 同向同时成立时，候选行组合信号列显示 ★，详情区列出四个部件——对应"趋势启动/趋势反转窗口"。
- **过度延伸观察**：第三个页签单独列出阶段判定为"过度延伸"（方向已确认但偏离MA20超过阈值，默认3ATR）的品种，双向按爆发指数排名，不受前5限制；延伸品种同样参与多空主榜排名，主榜"趋势·阶段"列合并显示趋势方向、阶段与持续交易日（悬停查看阶段原因），详情区附阶段原因与偏离ATR。延伸阶段趋势仍强但追单风险高，定位是回调/衰竭观察而非启动买点。
- **反转雷达**：第四个页签，品种级反转观察（与方向扫描互补）——强势衰退警报（五日前RPS20≥90且五日下滑≥15，跌破70升级）、RPS阶梯（RPS20<RPS60<RPS120 且 RPS120≥80 = 衰退排列；RPS20>60>120 且三周期同步升降 = 扩散翻多/翻空）、价涨仓减按趋势背景定性：下跌趋势中=回补反弹（空头平仓推动，勿当反转追多），多头趋势中=减仓上行（新资金未接力的资金背离警示，不是看空信号），无趋势背景才泛称疑似空头回补。警报优先排列，其余按|RPS五日变化|排序；基差/库存未接入，期限确认仅用期货Carry。
- **结构雷达（商品独有第二套系统）**：第五个页签，把商品期货区别于股票的资金/现货/跨期/曲线/库存五维度从爆发指数的散分项里独立出来，回答"这波趋势背后有没有真实资金与真实供需支撑"。**资金(OI)**＝价格方向×持仓变化的资金性质（价涨仓增"新多进入"满分，价涨仓减"空头平仓"仅3分低质量，价跌仓增"新空进入"，价跌仓减"多头撤退"），并用5日相对20日的持仓增速判"强化/减弱"；**现货(基差)**＝现货与基差5日变化是否同向确认趋势（两者同向10分、仅一项同向5分，需导入fundamentals.csv）；**跨期(月差)**＝近远月价差变化方向（走扩"近端转紧"利多、收窄"近端转松"利空，当前价差符号同向再加2分）；**曲线(期限结构)**＝Back/Contango对齐6分＋Carry动量同向2分＋五日拐点2分；**库存**占位（当前导入仅含现货与全品种OI，未接入库存，不计分）。五维度各按0–10分对多空两方向分别计分，缺失维度不计入可用分、按可用分归一，未导入现货的品种覆盖为3/5。输出"偏多/偏空"结构方向与多空结构分；结构方向与价格趋势一致时给"强/中/弱"结构质量（做多候选表新增"结构"列），**二者相反且结构分≥55时判"多/空头酝酿"并高亮**——对应"库存→基差→月差/期限结构→OI先变、RPS/ADX/突破后动"的提前观察区，背离行优先排列。点击行查看五维度分解与结论；其为观察池，不构成方向建议（背离≠已确认趋势，期权仍受方向闸门约束）。
- **10倍潜力模型（买方专用）**：每个候选品种详情区给出独立于爆发指数的100分模型——品种发动机80分（趋势启动25=平台突破+启动信号+四重共振、RPS15、ADX/DI10、OI+成交10、基差/月差/库存10、IV状态10=IV−HV20便宜度6+ATR压缩2+实际突破2，缺失按可用分母归一）＋合约层20分（Delta位置6+相对Gamma4+DTE5+流动性5）。候选池只选方向正确、|Delta|0.10–0.40、DTE7–30的轻中度虚值合约：|Delta|0.15–0.30与DTE7–15为甜区（便宜+有Gamma爆发力，标的无需极端行情即可穿越执行价）；IV相对HV20溢价>30%标"已透支"（方向对也可能被Vega反吃）。总分≥80高潜力（列表标"10倍高"）、60–80中、<60低，输出最优 Call/Put 合约与Delta/DTE/IV/Gamma/流动性状态。无买卖盘口，仍是研究观察而非买入指令。
- **三档可交易曲线**：`数据口径限制`之外，采集层（`raw/curve/{date}.csv`）自 20260918 起（含当日回填）保存全部有成交的真实月合约快照，并随快照版本一并归档（reload 不丢失）；详情区"期限结构"表展示剔除临近交割（≤5天）后按 OI 排序的主力/次主力/第三活跃三档与曲率（近+远−2×中）。更早快照无该文件时曲线表显示占位说明，Carry 动量不受影响。
- **数据口径限制**：库存/基差来自 `data/supplemental/fundamentals.csv` 外部导入，未导入时相关评分与信号按缺失处理；仅有单日期权快照，无法计算IV Rank，用IV−HV20溢价替代；全部为日线参考值，无买卖盘口，输出是研究观察名单而非可执行买入清单。期权链只覆盖当日主力/次主力合约对应的挂约月份——若期权挂月与主力月不一致（如低硫燃料油挂在远月），该品种可能没有可评估合约，表现为"无合约"而非数据缺失。

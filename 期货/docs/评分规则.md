# EMA20 趋势雷达评分规则

交易范围为五家商品交易所，零成交品种跳过。所有窗口单位为交易日。默认至少需要 280 根连续有效主力 K 线，当前篮子不少于 20 个品种。

## 唯一趋势线

系统只计算和展示 EMA20：

```text
EMA20 = close.ewm(span=20, adjust=False).mean()
趋势强度 = (EMA20[t] - EMA20[t-5]) / ATR14
价格距离 = (close - EMA20) / ATR14
```

趋势强度按绝对值分级：小于 0.25 为弱，0.25 至 0.75 为中，达到 0.75 为强；正值偏多、负值偏空。价格距离保留方向，正值表示价格在 EMA20 上方，负值表示在下方。

## 是否可做

满足以下条件才标记“可做”：

- 价格位于 EMA20 的正确一侧；
- EMA20 方向与交易方向一致，且强度至少为中；
- 价格到 EMA20 的顺向距离不超过 2 ATR；
- ADX、DI、方向 RPS、数据覆盖等原有质量门槛通过。

顺向距离在 2 至 3 ATR 之间时标记“等回踩”；超过 3 ATR 标记“不可追”。价格位于错误一侧、EMA20 走弱或反向、输入缺失、质量门槛失败时均不可做。该结论是规则判断，不是胜率或收益预测。

## 其他因子

RPS、突破、ADX/DI、ATR、量仓、期限结构和基差仍作为趋势强度、启动、风险与质量证据，但都不能生成或替代新的趋势线。缺失模块不按零分处理，系统同时展示获得分、可用满分与覆盖率。

复权价格仅用于技术指标；真实主力价格保留为 `raw_close`。量仓和月间价差使用固定主力/次主力代码，不能把持仓变化解释成单边新增多头或空头。

参数位于 `strategy_config.json`。默认值为：中等强度 0.25 ATR、强趋势 0.75 ATR、可做距离 2 ATR、禁止追单距离 3 ATR。

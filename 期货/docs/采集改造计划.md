# 期货数据采集改造

目标：获取五家商品交易所的真实月份合约、主连复权与映射，生成可审计的品种总持仓与期限结构。

采用分交易所、分交易日保存，保留每日合并 CSV。相比只修补原脚本，这可隔离失败和补采；相比引入数据库，保持现有使用方式且无需额外服务。

实施顺序：
1. 编写错误日期、异常OHLC、负持仓、重复记录、失败重试、缓存损坏、合成合约重复统计测试。
2. 实现带节流的接口客户端、校验、原子保存和文件哈希完成凭据。
3. 使用期货交易日历，普通合约和合成合约分开获取。达到返回上限按合约细分；基础信息上限无法可靠拆分时阻止完成。
4. 比较在市合约与日线覆盖，对缺失合约逐一补采，仍缺失则记录失败，不发布不完整的每日合并数据。
5. 期权基础信息按期货标的分组获取，行情按交易所请求、缺失合约补采。
6. 输出全合约OI、总成交量与原始合约期限结构。基差需另接现货数据，缺失不可当作零。
7. 添加命令行、小批量联网验证和使用文档；报告接口权限或覆盖限制。

完成凭据只表示数据通过当前代码校验，不代表供应商数据绝对正确。缺数据宁可失败，不将缺失推定为零。

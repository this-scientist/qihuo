# 商品期货趋势分与启动分

用户目标：五家国内商品交易所，只做明确趋势，寻找适合进一步评估买方期权的趋势启动品种。当前数据范围为主连和主力/次主力，排除零成交品种。

实施方案：沿用CSV；增加 `history.py` 处理历史真实主力与换月复权，`strategy.py` 计算指标和分数，`screen_futures.py` 输出多空榜单和数据质量报告。相比简单按RPS排序，此方案同时确认方向与突破；相比增加复杂预测模型，所有分值可解释并直接对应原策略。

1. 主力历史以每天 `fut_mapping` 对应的真实合约构建。仅请求历史上成为主力的合约及当前次主力；换月点以前一交易日新旧主力同日收盘比作向前连续调整。缺重叠价格/交易日不填补，记录缺失。原始价格保留，复权序列只用于技术指标。
2. MA20/60/120、归一化斜率、发散度；RPS20/60/120按同日篮子涨跌幅百分位，空头使用100-RPS；唐奇安20/55必须排除当前日；ATR14与ADX14按Wilder平滑，增加5日变化、ATR%历史252日分位、ATR14/60日均值。
3. 趋势分权重MA20、RPS20、突破20、ADX/ATR15、量仓15、期限结构/基差10。量仓基于当前固定的主力/次主力两个合约比较，不将历史角色更换产生的OI变化计为资金增长。期限结构最多5分：相同月对的5日近减远价差变化，另5分基差当前缺失。缺模块不记成0，输出获得分/可用满分、标准化0—100分、覆盖率和缺失原因。
4. 启动分九项权重：近期MA20/60穿越10、RPS20跃升15、短期领先长期10、近期基底突破15、ADX从低位抬升15、ATR压缩转扩张15、固定合约OI增长10、温和放量5、固定月对强化5。缺数据处理同趋势分。
5. 明确多空方向、ADX/DI、RPS和均线结构先作门槛；已确认趋势使用MA20/60/120排列，启动观察允许MA120尚未完成排列，但要求MA20/60方向一致、ADX>=20、RPS20>=90及近期突破。启动榜默认至少6项命中、65启动分、70趋势分，均线偏离不超过3ATR。榜单不凑数。
6. 至少280个连续有效主力日线，当前有效篮子用于同日RPS。新上市历史不足列入排除清单；篮子少于20时不发布正式榜单。所有计算截断到指定交易日，历史RPS为当前篮子的回看，不是消除幸存者偏差的回测。
7. 配置文件可改ADX/RPS门槛、最低分、最少命中数、偏离上限、篮子/历史长度与top数量。参数为待验证的筛选规则，没有将分数解释成胜率。
8. 输出全部品种指标、多空评分、确认趋势榜、启动榜、排除清单、质量报告和简明Markdown日报。只产生品种观察名单，不生成期权下单建议；实际买方期权适配需另查IV、期限和报价。

测试顺序：先写并运行换月价差不产生收益、唐奇安无当前日、ATR平滑、RPS强弱/并列、未来数据不影响过去、震荡不进榜、缺模块覆盖率、多空对称、榜单不凑数、历史/篮子不足测试；再实现，运行全套回归与真实采集验证。

# 商品期货 EMA20 趋势筛选

目标：在五家国内商品交易所中，只用 EMA20 判断趋势位置和方向，寻找值得进一步评估买方期权的品种。

1. 主力历史以每天的真实主力映射构建；换月使用同日重叠收盘比连续复权，原始价格同时保留。
2. 唯一趋势线为 EMA20。系统计算 EMA20 的五日 ATR 标准化斜率，以及当前价格到 EMA20 的 ATR 标准化有向距离。
3. 斜率绝对值小于 0.25 为弱、0.25 至 0.75 为中、达到 0.75 为强。正负号给出多空方向。
4. 只有价格站在正确一侧、斜率同向且至少为中、顺向距离不超过 2 ATR，并通过 ADX/DI、方向 RPS 和数据质量门槛，才评价为可做。
5. 距离在 2 至 3 ATR 时等待回踩；超过 3 ATR 不追。错误侧、弱趋势、反向、输入缺失或质量不足时不可做。
6. RPS、突破、ATR、量仓、期限结构与基差继续提供相对强弱、启动、风险和商品结构证据，但不再引入任何其他趋势线。
7. 输出包括 EMA20、趋势方向、强弱等级、价格距离、可做结论、原因、商品阶段、风险标记和期权候选。榜单不凑数。
8. 所有参数均为待验证规则，不应解释成胜率。历史研究严格截断到信号日，避免未来数据进入判断。

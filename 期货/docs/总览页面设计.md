# 商品期货 EMA20 总览与可配置筛选

目标：在真实日线数据上浏览大类与品种走势，并以 EMA20 作为唯一趋势线自由筛选。

视觉采用浅色研究工作台。图表只展示价格与 EMA20；结果表和详情面板优先展示 EMA20 趋势强弱、价格到 EMA20 的 ATR 距离和“是否可做”结论。

筛选器可使用 EMA20、EMA20 五日 ATR 斜率、价格距离、RPS、ADX/DI、突破、ATR、固定主次合约量仓、期限结构、商品阶段和决策状态。缺失数值不能通过比较，已下线因子不会从旧快照恢复。

机会分组遵循统一结论：可做进入重点研究，2—3 ATR 进入等待回踩，超过 3 ATR 或趋势不合格进入风险回避。期权自身的 IV、期限、Greeks、流动性和盈亏比在标的通过后独立评价。

前端使用无构建依赖的 HTML/CSS/JS 和离线 SVG 曲线；浏览器不接触行情访问令牌。响应式布局保持 EMA20 结论在窄屏上仍优先可见。

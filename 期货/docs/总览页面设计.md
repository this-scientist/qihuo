# 商品期货总览与可配置筛选

目标：在真实日线数据上浏览大类与品种走势，自由选择筛选因子和阈值。

视觉：浅色研究工作台，左侧分类导航，主区域曲线与结果表，右侧因子配置；以蓝色区分操作，曲线颜色保持稳定。

内容：首屏为各大类等权曲线；点击大类切换全部品种对比，点击结果查看单品种及MA20/60/120。包含数据日期、缺失因子、排除品种和计算口径。

交互：类目与曲线选择同步，因子规则可增删、启停、设置比较运算、数值或另一个因子；选择全部/任一满足、方向、结果排序。可保存、导入和导出配置。响应式布局和减少动态效果偏好。

架构：复用Python指标与已验证数据，新增 dashboard_data.py 生成无凭据的JSON；标准库HTTP服务在127.0.0.1提供页面和API。前端为无构建依赖的HTML/CSS/JS，离线SVG曲线。没有行情访问令牌进入浏览器。

分类：黑色、贵金属、有色与新能源、能源、化工、农产品、其他；每个有效品种仅归一类，黑色包含螺纹、热卷、铁矿、焦煤、焦炭、硅铁、锰硅。分类支持文件修改。大类曲线由当前有效成分在共同交易日期起点归一化后的价格指数等权平均，非交易所指数；展示实际有效成分数量与排除情况。

因子：价格/均线、涨幅与均线斜率、RPS原始值与方向强度、ADX/DI、Donchian突破、ATR百分比/分位/变化、固定主次合约OI/成交量、月间价差、原版趋势和启动分、信号。百分比因子统一显示百分点。基差和现货不可用，规则选择后结果为数据不足，不填零。禁止以缺失数值通过比较。

结果：自定义匹配与原版策略分数明确区分；不自动施加旧MA排列或70分门槛。无条件时显示范围内全部品种；方向选项决定方向RPS、突破与启动信号。明细展示所有已开启规则的左右值、比较和通过/未通过/缺失状态。

实施计划：
1. 编写分类覆盖、等权指数与百分比转换测试，实现数据导出。
2. 编写规则AND/OR、因子比较、缺失和配置校验测试，实现前端规则模块。
3. 实现总览、大类对比、单品种均线、因子编辑与配置保存。
4. 用68品种真实数据运行服务，通过浏览器验证类目、规则、曲线、配置和窄屏；补充启动说明。

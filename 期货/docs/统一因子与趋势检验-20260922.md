# 统一因子与趋势检验

数据日：2026-09-21。主用途：5-20个交易日波段观察。版本：price-swing-v1。

## 结论

没有证据支持目前任何一套方法为“最准确”。当前方案是可解释、无未来数据的价格趋势判定规则，不是已验证的收益预测器。完整模型在20日总体样本优于旧版可重建价格部分，但不优于所有删减版本，且后两段表现不稳定；不能据此宣称增加因子提高了准确率。保留透明的固定分组权重，禁止在本次样本上反复调参后再把结果当作独立验证。

页面统一使用一份商品决策：价格趋势方向、商品结构方向各自独立，同一维度跨页一致。期权评分另含IV、期限、Delta和流动性，不替代标的价格趋势。

## 因子取舍

| 因子 | 保留用途 | 本次证据与处理 |
|---|---|---|
| 收盘/MA20、MA20/MA60、MA20斜率 | 价格方向 | 同属一个40分组，避免每个条件独立占大权重；删组版本有时更好，未证明不可替代 |
| 5日/20日绝对涨跌幅 | 价格方向 | 用ATR归一，合计35分；展示原始百分比；单纯20日动量作为基准 |
| DI差 / ADX | 有向趋势力度 | 合计25分；ADX本身无方向；不可把ADX上升直接解释为看涨 |
| RPS5、RPS20 | 横截面强弱与排序 | 保留原始涨幅排名，空头不翻转显示；单因子未稳定优于价格基准 |
| RPS“加速度” | 变化提示、爆发证据 | 实际是RPS20五日差；单独预测5/20日均弱，不参与主方向定向 |
| RPS60/120、MA120 | 详情/历史研究 | 与较短周期高度同源且更滞后；退出5-20日主方向直接计分，不据此断言长期无效 |
| 突破20/55日、近期突破 | 启动与爆发证据 | 不再作为另一个独立方向；未完成单独收益增量检验 |
| ATR、ATR分位/扩张、偏离ATR | 归一、风险、爆发 | 波动无方向；过度延伸不是反向信号；爆发贡献未独立验证 |
| 总OI、OI变化、量比 | 参与度/量价组合 | 固定主次合约口径，真实持仓数量；不能判断“新多/新空”身份；历史不可完整复建，预测增量待验证 |
| VOL_RPS、OI_RPS | 备用排序 | 是原始量仓的再次排名，不额外给趋势加权 |
| 主次合约OI转移 | 换月解释 | 帮助区分移仓与全品种资金变化，不独立给趋势定向 |
| 月差、Carry、Carry变化 | 独立商品结构 | 同一曲线信息，合成一组10分，不重复两票；Carry水平也受季节性和持有成本影响 |
| 曲率、第三活跃合约 | 补充观察 | 不与固定近远月对混合计算历史变化；未证明有增量收益 |
| 现货、基差 | 独立结构组 | 有来源、日期、身份匹配时使用；缺失不虚构 |
| 库存/仓单、席位多空持仓 | 待接入 | 本地该日无可用数据，显示未接入；不能拿总OI冒充 |
| IV/HV、DTE、Delta/Gamma、期权流动性 | 期权合约层 | 不参与期货主方向；期权专项评分与标的爆发指数分别命名 |
| 启动分、趋势阶段分、旧总分 | 派生结果 | 不再把它们反复叠加成新的趋势“证据”；T0-T5是规则阶段，不展示为真实历史迁移 |

“退出定向”“待验证”不等于永久没用。这里只根据口径、重复性和当前样本说明角色。

## 价格方向公式

所有输入截至当日收盘。公开数据接口中的收益和斜率用百分数（3代表3%）。设clip将数值限制到[-1,1]；A为ATR14，C为复权收盘。

```text
P = mean(clip((C-MA20)/(2*A)),
         clip((MA20-MA60)/(3*A)),
         clip(slope20*MA20/(100*A)))
M = mean(clip(return5 / ((A/C*100)*sqrt(5))),
         clip(return20 / ((A/C*100)*sqrt(20))))
D = clip(2*(DIplus-DIminus)/(DIplus+DIminus))
    * clip((ADX-10)/20, 0, 1)
TrendScore = 40*P + 35*M + 25*D
```

TrendScore>=25偏多，<=-25偏空，中间中性。关键输入缺失则无方向，不回退到旧评分强行推荐。三个分组及阈值为先验规则，尚未校准为概率。RPS、OI和期限结构不修改主方向。

涨跌幅：当日=真实主力收盘/昨结-1；1日=复权收盘/前收-1；5/20日=复权收盘/前5/20个交易日收盘-1。RPS按同日有效篮子排名，平均名次处理并列，0最弱、100最强，单品种为50。RPS加速度=RPS20(t)-RPS20(t-5)，不是二阶导数。

标的爆发指数：20日突破25、方向RPS变化20、ADX增量20、ATR扩张15、量比10、价格同向且增仓10。缺失不归一抬高分数，同时显示可用权重。指数不是概率，也不代表期权潜在倍数。

结构：量价、现货基差、期限曲线、库存四组，每组10分；月差与Carry的多空证据取平均组成曲线组。分别计算可用组上的多头/空头分，净分>=10偏多，<=-10偏空，其余中性。覆盖率独立显示，防止少数可用因子的高分被误认为信息完整。与主趋势比较后另标同向/背离。

统一模型20日分段命中率：70.97%、47.76%、46.88%；平均方向净收益：+6.50%、-1.61%、-1.22%。总体优势主要来自首段，稳定性不足。去掉价格组的总体命中率更高也不能证明应删除价格组：样本覆盖不同、时段表现不稳，没有独立保留数据。

上述是探索性事件检验，不是实盘组合回测：当前篮子有幸存者偏差，同日品种相关，固定日期样本有限；复权主连未完整模拟换月、滑点与涨跌停，OI/结构缺乏完整历史验证。没有做独立样本检验，不能把规则分当胜率。

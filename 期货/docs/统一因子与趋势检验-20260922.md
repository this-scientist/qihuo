# EMA20 统一因子与趋势检验

当前模型版本为 `price-swing-v2-ema20`，服务于 5—20 个交易日的波段观察。系统不宣称该规则“最准确”；它是一套可解释、无未来数据的筛选方法，不是收益概率模型。

## 统一口径

- 价格趋势只由 EMA20 的方向、强弱和价格相对位置定向。
- 趋势强度为 EMA20 五日变化除以 ATR14；小于 0.25 为弱，0.25 至 0.75 为中，达到 0.75 为强。
- 价格距离为 `(收盘价 - EMA20) / ATR14`，保留正负方向。
- 正确侧、同向中强趋势、顺向距离不超过 2 ATR 且质量门槛通过时评价为可做；2—3 ATR 等回踩；超过 3 ATR 不追。
- RPS、ADX/DI、突破、ATR、量仓和期限结构只提供确认、风险或商品结构信息，不再产生额外趋势线。

页面、筛选器、期权候选、历史研究和 AI 上下文都读取同一份决策记录。关键输入缺失时结论为不可用，不通过旧分数或缓存字段回退。

## 验证边界

历史检验按信号日截断数据，下一交易日开盘进入，第 N 日收盘退出，并计入假设成本。中性和缺失样本单独统计，避免只展示被筛中的样本。

当前篮子存在幸存者偏差，同日品种也高度相关；复权主连无法完整模拟换月、滑点、涨跌停和期权盘口。因此，规则分、强弱等级和“可做”都不是胜率承诺，仍需在独立样本中持续验证。

# EMA20 趋势研究闭环与期权独立页

系统的价格趋势判断只有一条趋势线：EMA20。趋势阶段、历史验证、总览、筛选器、期权页和 AI 上下文必须复用同一份 EMA20 评估，不得各自重新定义方向。

阶段判断使用 EMA20 五日 ATR 标准化斜率、价格到 EMA20 的有向 ATR 距离，以及 DI、ADX、RPS 等确认信号。趋势强度分为弱、中、强；距离分为可做、等待回踩和不可追。弱趋势、方向冲突、输入缺失或质量门槛失败均明确标记不可做。

历史验证以当日收盘生成信号、下一交易日开盘入场、第 N 个交易日收盘评估，计算方向收益和最大有利/不利波动。所有因子只使用信号日及以前数据；当前有效篮子的结果只属于探索性事件研究，不输出虚构的组合净值或期权收益。

所有发布快照保存并校验哈希。成功更新才切换活跃快照，失败继续提供上一个有效版本。旧快照载入时按当前因子白名单过滤，已下线字段不能重新进入页面。

期权页使用同一标的趋势结论，并独立展示 IV、期限、Greeks、流动性和情景盈亏。未接入可成交盘口时仅作日线观察，不确认实盘可执行性。

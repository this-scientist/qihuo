# 趋势研究闭环与期权独立页

授权范围：补齐已指出的趋势阶段、历史验证、更新与历史记录、量仓/基差覆盖，并独立展示期权。

页面：保留总览与自定义筛选；加入趋势阶段列/过滤、数据日期与异步更新状态、历史快照和配置运行记录。独立 research.html 提供收盘信号事件验证；独立 options.html 展示真实主次合约对应期权链、日线量仓、HV、参考IV、到期损益情景与缺失盘口状态。

阶段：基于因果MA/斜率/DI/ADX/RPS判断方向形成、中短期强势、完整排列持续趋势；近期新突破且ADX从低位抬升、RPS增强视为技术启动。偏离MA20超过3ATR单独覆盖为过度延伸；ADX较弱、方向缺失分为震荡或趋势减弱。门槛配置化，不用总分70或MA60>MA120把所有未入旧榜品种称为震荡。

验证：当日收盘生成信号，下一个交易日开盘入场，第N个交易日收盘评估，计算方向收益、最大有利/不利波动、信号后是否失效。样本不重叠；仅统计已结束事件，未结束单列。计算截至信号日的RPS/技术数据，禁止把当前主次合约OI套到历史主次身份。默认技术启动事件；支持用户技术规则、持有日数、往返费用基点。当前存量历史使用当前有效篮子，明确标为探索性事件研究，非无幸存者偏差回测，不输出虚构组合净值或期权收益。

数据：所有发布快照保存到data/processed/dashboard/YYYYMMDD.json并校验哈希，保留历史；服务异步更新到指定已收盘日期，成功才更换活跃快照，失败继续提供旧快照，任务状态持久化。服务可重载本地数据无需重启。每次因子运行可保存参数、品种、数据哈希。

基本面：固定主次OI口径不改变；新增本地可导入补充数据，来源和可用日期必须明确，历史值不越过available_date。支持同报价单位的现货/基差与外部全品种OI；未提供时显示缺失，绝不改称全品种资金。导入样例模板不含模拟行情。

期权：仅采集已选真实主次合约对应的期权元数据和当日日线，分页/缓存/有效日期/标的/报价校验。五交易所分别报告覆盖或接口失败。opt_basic依据OP+真实期货TS_CODE精确关联；剔除未来上市、过期、错标的和无效报价。Black76从日线收盘反求参考IV，明示参数和美式期权的欧洲模型近似；真实标的单月HV单列，主连ATR不冒充IV。未接入买卖盘口时仅“日线观察”，不确认可执行买方机会。终值情景按买方权利金计算，乘数缺失不输出手成本；模型参考不是实盘期权回测。

# 商品期权买方系统简化设计

## 目标

把原《商品期权买方趋势交易系统设计》压缩为一个可开发、可回测、可逐步扩展的最小闭环系统。

系统只回答三个问题：

1. 商品是否出现清晰的价格行为机会？
2. 未来 5、10、20 个交易日的价格路径是否值得研究？
3. 是否存在一个流动性合格、风险收益合理、仓位可控的期权表达方式？

第一版不追求功能完整，只追求逻辑闭环、无前视偏差、可复现、可回测。

## 核心原则

- 价格行为产生信号，指标只做验证，期权只做执行工具。
- 商品机会评分和期权可交易性必须分离。
- 不预测唯一目标价，只输出未来价格路径分布。
- 没有经过校准的概率不能生成正式交易计划。
- 仓位必须同时受计划止损风险和全部权利金风险约束。
- 没有好机会时允许空仓，不凑满观察池、候选池或持仓池。

## 最小闭环

系统主流程固定为：

```text
价格行为事件
  -> 商品信号验证
  -> 历史路径分布
  -> 期权执行评估
  -> 双账本仓位
  -> 路径回测
```

任何模块缺失时，系统必须降级为研究输出，不得生成正式交易计划。

## 三层池

| 层级 | 上限 | 入池依据 | 作用 |
| --- | --- | --- | --- |
| 商品观察池 | 12 个 | 有价格结构或关键事件雏形 | 日常跟踪 |
| 商品信号池 | 5 个 | 价格行为事件 + 商品验证通过 | 做路径概率研究 |
| 期权交易池 | 0-3 个 | 期权执行评估 + 风险预算通过 | 生成交易计划 |

商品观察池和商品信号池不得读取期权便宜或昂贵来改变商品排序。期权数据只能决定是否进入期权交易池。

## 第一版只做三个交易模型

| 模型 | 名称 | 商品信号 | 期权动作 |
| --- | --- | --- | --- |
| A | 平台突破 + 资金确认 | 突破长期区间并被接受 | 研究平值或轻度虚值趋势启动型期权 |
| B | 趋势回踩 + 二次启动 | 原阻力/支撑转换后再次推动 | 研究更好入场位置 |
| C | 结构反转 + 新方向确认 | 原趋势破坏后形成新方向 | 研究空翻多或多翻空机会 |

暂不实现复杂 K 线形态、机器学习模型、产业知识图谱、固定多倍收益概率排名。

## 价格行为定义

### 结构方向

每个商品每日输出：

- `structure_side`: `bullish`、`bearish`、`range`、`transition`
- `lifecycle`: `base`、`start`、`advance`、`acceleration`、`exhaustion`
- `event_type`: `breakout`、`pullback`、`failed_breakout`、`structure_break`、`reversal_confirmed`、`none`

系统不得只用一个综合阶段标签替代这三个字段。

### 有效突破

以上行突破 60 日平台为例，初始规则为：

1. 收盘价突破此前 60 日最高价；
2. 突破幅度大于 `0.3 * ATR14`；
3. 收盘位于当日振幅上方 25% 区域；
4. 最近 10-20 日存在波动收缩或横盘蓄势；
5. 成交量高于 20 日均量时，作为验证而非主信号。

反向突破镜像处理。

### 首次回踩

有效回踩必须同时记录：

- 原突破位；
- 回踩最低/最高点；
- 回踩持续天数；
- 是否跌破或升破结构失效位；
- 回踩后是否重新沿原方向推动。

### 结构收益风险比

```text
structure_rr = abs(target_price - entry_price) / abs(entry_price - invalidation_price)
```

`structure_rr` 只是期货标的的技术空间，不等于期权盈亏比。

## 商品信号验证

商品信号验证只用于确认价格行为，不替代价格行为。

| 验证项 | 用途 |
| --- | --- |
| RPS20 / RPS60 | 判断相对强弱 |
| OI 变化 | 判断是否有新增参与 |
| 成交量 | 判断突破或回踩是否被接受 |
| ADX | 判断趋势成熟度 |
| ATR | 判断空间和风险尺度 |
| 基差/月差 | 后续版本用于商品基本面确认 |

第一版商品机会评分：

| 维度 | 权重 |
| --- | --- |
| 价格行为与市场结构 | 40 |
| 未来价格空间 | 25 |
| 资金参与与相对强弱 | 25 |
| 数据质量与可交易基础 | 10 |

该评分只用于商品排序，不读取期权 IV、Delta、Theta 或期权收益。

## 历史路径分布

对每个商品信号，系统寻找历史相似事件，并统计未来 5、10、20 个交易日：

- 终点收益分布；
- 期间最高收益分布；
- 期间最低收益分布；
- 首次触及目标所需天数；
- 先触及目标还是先触及失效；
- 最大逆向波动。

输出至少包括 P10、P25、P50、P75、P90。

## 防前视规则

历史样本必须满足：

```text
s + H <= t
```

其中 `s` 是历史信号日，`H` 是观察窗口，`t` 是当前预测日。未完整走完观察窗口的样本不能参与当前预测。

必须遵守：

- 波峰波谷只能使用当时已经确认的数据；
- 训练、验证、测试按时间滚动或扩展窗口切分；
- 标签观察期之间必须清洗重叠；
- 同一轮趋势中的连续信号要合并为独立事件；
- 每个概率输出必须给出样本数和独立事件数。

## 概率可信度

| 等级 | 标准 | 允许动作 |
| --- | --- | --- |
| 研究级 | 样本不足或未校准 | 只展示研究结果 |
| 验证级 | 样本外测试通过但稳定性未验证 | 允许模拟交易 |
| 可交易级 | 校准、成本、稳定性验证通过 | 可参与正式仓位决策 |

第一版默认输出研究级或验证级，不自动生成正式下单计划。

## 期权执行评估

期权评估只在商品信号通过后运行。

硬门槛：

- 期权方向必须与商品信号一致；
- 合约成交量、持仓量、价差和深度满足配置门槛；
- 到期时间覆盖预测窗口和退出规则；
- 期权对应的实际期货合约价格口径正确；
- 时间戳一致，或明确降级为研究值。

评估字段：

- 流动性；
- Delta、Theta、Vega；
- IV 相对历史分位；
- IV 相对预测实现波动率；
- 路径执行后的期望收益；
- 全部权利金损失概率；
- 组合相关性风险。

`IV/HV > 30%` 只作为高风险提示，不作为跨品种绝对阻断线。

## 路径执行模拟

期权收益必须经过执行规则，不能只用未来最高价计算理论收益。

默认动作：

| 事件 | 动作 |
| --- | --- |
| 突破确认 | 建试错仓 |
| 回踩确认 | 风险允许才加仓 |
| 触及第一目标 | 部分止盈或上移保护位 |
| 触及主要目标 | 按规则减仓 |
| 跌破失效位 | 退出 |
| 时间价值衰减过快 | 减仓或退出 |
| 到期过近 | 提前平仓或进入行权处理 |
| 流动性恶化 | 停止加仓并评估退出压力 |

如果执行规则不会在路径高点卖出，系统不得使用高点理论价作为已实现收益。

## 双账本风险

每笔交易同时计算：

| 账本 | 计算 | 用途 |
| --- | --- | --- |
| 计划止损风险 | 预计止损差额 × 手数 × 合约乘数 + 成本 | 日常仓位 |
| 全部权利金风险 | 权利金 × 手数 × 合约乘数 + 成本 | 极端损失 |

仓位取两者约束下的较小手数。

示例：

- 账户权益：100000；
- 计划止损风险上限：0.5%，即 500；
- 全部权利金风险上限：1%，即 1000；
- 单手权利金：500；
- 计划止损：35%。

则：

- 按计划止损风险最多 2 手，计划亏损 350；
- 按全部权利金风险最多 2 手，极端损失 1000；
- 批准手数为 2 手。

如果全部权利金风险超过上限，即使计划止损风险合格，也不得开仓。

## 数据口径

系统必须区分：

| 序列 | 用途 |
| --- | --- |
| 趋势分析连续序列 | 价格行为、RPS、ADX、ATR |
| 全月份期货数据 | OI 汇总、主力迁移、期限结构 |
| 期权对应实际期货合约 | 期权估值、Greeks、收益映射 |

复权连续价格不得直接代入期权定价。

商品信号输出：

  "structure_side": "bullish",

  "event_type": "breakout",

## 验收标准

- 商品观察池不超过 12 个，商品信号池不超过 5 个，期权交易池不超过 3 个。
- 商品排序不得读取期权 IV、Delta、Theta、期权 EV 或期权是否合格。
- 没有价格行为事件时，即使 RPS、OI、ADX 都支持，也不得进入商品信号池。
- 历史相似样本必须满足 `s + H <= t`。
- 每个概率输出必须包含样本数和独立事件数。
- 未达到可交易级的模型不得生成正式下单计划。
- 期权收益必须经过路径执行模拟。
- 仓位必须同时通过计划止损风险和全部权利金风险。
- 复权连续价格不得用于期权定价。
- 示例案例中的商品目标、失效价、期权方向和风险预算必须一致。

## 开发顺序

### V1：行情识别

实现价格行为、A/B/C 模型、RPS/OI/ATR、历史路径分布。

目标：证明系统能无前视地识别值得研究的行情。

### V2：期权表达

接入真实期权链、流动性、IV、Greeks、路径执行模拟。

目标：证明期权表达后的收益分布可验证。

### V3：仓位执行

加入动态仓位、组合相关性、双账本风险和完整策略回测。

目标：形成可模拟、可复现、可审计的交易决策流程。
